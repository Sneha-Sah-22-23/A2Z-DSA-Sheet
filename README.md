# A2Z Striver DSA Sheet

My solutions and notes while working through Striver's A2Z DSA Sheet, one problem at a time.

## About

I'm a final-year B.Tech CSE student building strong DSA fundamentals alongside my DevOps/Cloud work. This repo tracks my progress through the sheet: problem solutions, the approach behind each one, and complexity notes.

## Structure

```

└── ...
```

Each folder follows the order of the A2Z sheet. Each problem file includes:

- Problem statement or link
- Brute force approach
- Optimized approach
- Time and space complexity


## Approach

1. Try the problem on paper first.
2. Write the brute force, then optimize.
3. Note the pattern used (two pointers, sliding window, binary search, etc.).
4. State the time and space complexity.

## Patterns learned

- **Two pointers:** sorted array pair sum, palindrome check. O(n).
- **Sliding window (fixed size):** subtract the element leaving, add the element entering. O(n).
